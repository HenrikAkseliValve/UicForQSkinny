###################
QSkinny UIC Schema
###################

Qskinny UIC (User Interface Creator) format (prefixed .qskuic) is based upon Qt's UIC format. Format is not just copied over to allow QSkinny special features.

XML format is selected over Qt's QML format or somekinda INI format, because:
    1) QML has pointless javascript feature.
    2) XML formats are more commmon.
    3) Technically QML can be used with the Qskinny already.

For our Qskinny UIC format root tag is "<ui>" like Qt's UIC format.

Note that in tables below tag names may have text surrounded by "<" ">". These means variable text!
